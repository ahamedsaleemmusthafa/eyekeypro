Healthcare Data Entry ICR Rules

Standard guidelines for medical/dental claim code entry.

Rule 1: CAPITAL LETTERS ONLY

All alphabetic letters MUST be keyed in CAPITAL LETTERS, even if the image displays lowercase or mixed script.

Rule 2: Amount Fields

Do NOT key dollar sign ($) or commas. Enter plain digits e.g. Image $1,250.00 → Key 1250.00.

Rule 3: Date Fields

Do NOT key slashes (/). Enter contiguous MMDDYYYY digits e.g. Image 09/28/2026 → Key 09282026.

Rule 4: Tooth Surface

MUST add commas between surface letters e.g. Image mod → Key M,O,D.

Rule 5: ICD-10 Diagnosis Format

Do NOT key decimal dots (.) in ICD-10 codes e.g. Image m54.50 → Key M5450.
